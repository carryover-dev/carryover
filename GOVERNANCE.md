# Governance

Carryover is a Benevolent Dictator For Life (BDFL) project. The current BDFL is `@rohitsux`.

Decisions prefer consensus-seeking over voting. The BDFL reserves final say only when consensus cannot be reached.

All project discussion happens in public on GitHub. Private decisions, when unavoidable, are summarized back into the relevant public thread.

Before the v0.1.0 public announcement, two governance items must land: (1) move the repository to a dedicated GitHub Organization (no personal accounts), and (2) onboard a second admin so the project is never a single point of failure.

This document will be revisited and expanded toward a liberal-contribution model once the project has five or more regular contributors or the scope spans multiple subsystems.
